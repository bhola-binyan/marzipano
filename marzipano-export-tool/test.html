📊 Browser Console Tests

Open browser console and run these commands to test:

// Test if Marzipano is loaded
console.log('Marzipano available:', typeof Marzipano !== 'undefined');

// Test if JSZip will load
console.log('JSZip available:', typeof JSZip !== 'undefined');

// Test WebGL support
const canvas = document.createElement('canvas');
const gl = canvas.getContext('webgl') || canvas.getContext('experimental-webgl');
console.log('WebGL supported:', !!gl);

// Test File API support
console.log('File API supported:', !!(window.File && window.FileReader));

🐛 Debugging Tips

  • tourData error: Check browser console for "tourData not found" message
  • Image preview issues: Check if images load properly before clicking
  • Modal problems: Press Escape key or click outside modal to close
  • Export failures: Ensure you have scenes with images before exporting
  • Hotspot issues: Make sure to select a scene before adding hotspots

📝 Sample Test Data

For testing, you can use these types of panorama images:

  • 📱 360° photos from smartphones (usually equirectangular)
  • 🖼️ Downloaded panoramas from sites like Unsplash or Pixabay
  • 🎨 Rendered panoramas from 3D software (Blender, etc.)
  • 🔍 Any 2:1 aspect ratio image will work for testing
