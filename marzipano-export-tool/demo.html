🚀 Quick Setup Guide

1. Build Marzipano Library

Make sure the Marzipano library is built and accessible:

cd path/to/marzipano
npm install
npm run dev

This creates build/marzipano.js which the tool requires.

2. Start Local Server

The tool needs to run on a local server for file handling:

# Using Python
python -m http.server 8080

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8080

3. Prepare Test Images

For best results, use equirectangular panorama images (2:1 aspect ratio):

  • 360° photos from smartphones or cameras
  • Rendered panoramas from 3D software
  • Downloaded panoramas from stock photo sites
